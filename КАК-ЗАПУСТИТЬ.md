# Как запустить игру в Telegram

Игра — один файл `index.html`. Его нужно выложить на любой бесплатный HTTPS-хостинг,
а потом привязать к боту. Сервер держать включённым не нужно.

## Шаг 1. Выложить на GitHub Pages (≈5 минут)

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Нажми **New repository** → имя, например, `vocab` → **Public** → **Create repository**.
3. На странице репозитория: **uploading an existing file** → перетащи `index.html` → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/vocab/`.
   Открой его в браузере и проверь, что игра работает.

## Шаг 2. Создать бота и привязать игру

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. Кнопка в меню бота: `/mybots` → твой бот → **Bot Settings** → **Menu Button** →
   вставь адрес из шага 1 и подпиши кнопку, например «Играть».
3. (Необязательно) Ссылка-приложение: `/newapp` → выбери бота → название, описание,
   картинка 640×360 → адрес из шага 1 → короткое имя, например `words`.
   Получится ссылка `t.me/ИМЯ_БОТА/words` — её можно кинуть одногруппникам.

Готово: открываешь бота → кнопка «Играть» внизу слева.

## Как поменять слова

В `index.html` в начале скрипта есть список `WORDS`. Каждая строка выглядит так:

```js
{w:"lecture", ru:"лекция", d:"a formal talk on a serious subject ..."},
```

- `w` — слово, `ru` — перевод, `d` — определение;
- `alt:["exam"]` — другие написания, которые тоже засчитываются (необязательно).

Поправь файл и загрузи его на GitHub заново (Add file → Upload files) — игра обновится через минуту.

## Важно

- Прогресс («сложные слова») хранится на том устройстве, где играешь.
- Переводы составлены автоматически — сверь их с тем, что давал преподаватель.
